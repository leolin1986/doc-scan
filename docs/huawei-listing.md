## 应用简介（一句话描述，50字以内）
免费文档扫描工具，自动边缘检测、透视校正、图像增强，媲美扫描全能王。

## 应用描述（详细描述，500字以内）
DocScan 是一款完全免费的在线文档扫描工具，让您的手机秒变专业扫描仪。

【核心功能】
• 自动边缘检测 — 智能识别文档边界，自动裁剪多余背景
• 透视校正 — 倾斜拍摄的文档自动拉正，恢复端正效果
• 3 种扫描模式 — 黑白文档、彩色清晰、去阴影增强
• 手动调整 — 支持拖动四角精确裁剪，双指缩放查看细节
• 一键保存 — 扫描结果直接保存到相册或分享

【产品特点】
• 完全免费，无需注册登录
• 所有处理在手机本地完成，图片不会上传服务器
• 支持 JPG/PNG/WebP 格式
• 一次最多处理 3 张图片
• 中英文双语界面

【使用场景】
• 扫描纸质文档、合同、发票
• 拍摄书籍、笔记转为清晰电子版
• 证件、名片数字化存档
• 白板内容拍摄保存
